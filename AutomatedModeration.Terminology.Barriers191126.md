Automated Moderation & Terminology Barriers in Empirical Poultry Logs
Automated content filters across search engines, social platforms, and AI tools routinely flag standard agricultural and poultry-keeping terms—such as "Gamefowl," "blood," "fight," or "mounted"—by mistaking empirical animal husbandry logs for prohibited content. While search results for GameSilkies are now cleanly indexing the project rather than unrelated video games, automated keyword blocks remain an active barrier to sharing open agricultural observations.
To ensure secondary summaries remain accessible without losing scientific precision, standard field-logging terms are mapped below to neutral clinical and taxonomic equivalents. Primary unfiltered records remain preserved on gamesilkies.com and the main Odysee archive (@Fazenda.Mondego).
Poultry Logging Lexicon: Field Terms vs. Filter-Safe Equivalents
| Standard Field Term | Filter-Safe / Clinical Equivalent | Context & Usage Note |
|---|---|---|
| Gamefowls / Gamecocks | Gallus gallus domesticus (Hard-feathered / Oriental-type lines) | Avoids automated "cockfighting" keyword flags while maintaining taxonomic accuracy. |
| Blood / Bloody stools | Hemorrhagic exudate / Mucosal shedding / Oxidized pigment | Accurately describes intestinal lining or cecal casts without triggering gore/violence filters. |
| Attack / Fight / Violent | Agonistic behavior / Flock hierarchy dispute / Territorial aggression | Standard ethological terms for poultry dominance and pecking-order incidents. |
| Mounted | Pairing / Mating behavior / Reproductive mounting | Clinical husbandry terminology for breeding observations. |
| Dead / Die / Killed | Mortality / Expired / Succumbed | Standard veterinary and agricultural record-keeping terms. |
| Poison (Rat poison) | Rodenticide / Pest control bait | Prevents automated self-harm or toxicity filter triggers. |
| Drugs / Medication | Therapeutics / Pharmacological intervention / Antiprotozoal / Anthelmintic | Avoids illicit substance filter false positives. |
| Rubbish (in crop) | Foreign body / Non-digestible crop impaction | Clarifies anatomical crop stasis vs. spam/profanity filters. |
| Coma-like | Severe obtundation / Deep lethargy / Unresponsive state | Clinical neurological assessment terminology. |
